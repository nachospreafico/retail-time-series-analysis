# Retail Revenue Time Series Analysis

Time series analysis of historical transactional retail data to understand
revenue trends, seasonality, anomalies, and short-term forecasting.

## Data source

UCI Online Retail II dataset.

## Objectives

- Build a reliable revenue time series from raw transactions
- Analyze trend and seasonality
- Identify unusual periods and potential drivers
- Establish forecasting baselines
- Evaluate time-series forecasting models using temporal backtesting
